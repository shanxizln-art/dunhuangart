# 资产目录

把从 Aholo World 导出的文件放在这里：

| 文件名 | 说明 | 对应内容 |
|--------|------|---------|
| `scene.spz` | 洞窟高斯泼溅场景（下载包里的场景 SPZ） | 整个洞窟背景 |
| `actor-buddha.glb` | 佛像 GLB | 主尊佛像 |
| `actor-bodhisattva-l.glb` | 胁侍菩萨 GLB（左） | 胁侍菩萨 |
| `actor-bodhisattva-r.glb` | 胁侍菩萨 GLB（右） | 胁侍菩萨 |
| `actor-feitian-1.glb` | 散花飞天 GLB | 飞天 1 |
| `actor-feitian-2.glb` | 俯冲飞天 GLB | 飞天 2 |
| `actor-altar.glb` | 佛坛石台 GLB | 佛坛 |

**放好文件后改 `src/config.js` 里的 position/scale 对位即可。**

文件名不一致也没关系——改 config.js 里的 glb 路径就行。
